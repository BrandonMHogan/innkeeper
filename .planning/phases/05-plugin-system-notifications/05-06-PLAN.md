<objective>
Build the dashboard-facing surfaces for MOD-02 (module settings page: list, enable/disable, destructive-confirmation on disabling a depended-upon module) and MOD-04 (module nav entries for `HasUIPage` modules at `/modules/[module-name]`). This plan is purely additive UI/route work consuming the module contract that Plans 01-05 already built and proved — it introduces a new `backend/src/routes/modules.py` host-level route file (not itself a module, mirroring `auth`/`capture`'s host-level status) that reads the live `ModuleRegistry`/manifests assembled at startup to answer "what modules exist, what do they depend on, are they enabled."

Purpose: Close MOD-02 and MOD-04's user-facing success criteria — the last two requirement IDs for this phase — completing all eight MOD-01..MOD-08 roadmap requirements.
Output: `GET /api/modules/` + `POST /api/modules/{id}/toggle` routes, `/settings/modules` page, `/modules/[slug]` dynamic route rendering a `HasUIPage` module's content, nav entries that appear/disappear based on enabled state.
</objective>
