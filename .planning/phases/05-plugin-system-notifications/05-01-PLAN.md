<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| In-process module factory → ModuleRegistry | A module's factory function is trusted first-party code (no third-party modules ship this phase); still validated structurally via isinstance() before being trusted to satisfy a capability |
| ModuleLoader startup → FastAPI app | Loader output (routers, UI routes, collector tasks) is mounted into the live app process; a loader bug here is a startup-time failure, not a runtime request-time vulnerability |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Denial of Service | ModuleLoader.build_load_order | mitigate | graphlib.TopologicalSorter's CycleError is propagated as a fail-fast RuntimeError, never silently worked around — a circular module dependency crashes startup loudly instead of hanging |
| T-05-02 | Tampering | ModuleRegistry.register provides-conflict | mitigate | register() raises RuntimeError naming both providers on a Protocol-type conflict, preventing a malformed manifest from silently shadowing a legitimate provider |
| T-05-03 | Elevation of Privilege | Capability isinstance() signature mismatch (Pitfall 2) | mitigate | Every capability-wiring call wrapped in its own try/except in loader.py, logged and skipped rather than crashing the whole startup sequence or silently registering a broken capability as functional |
| T-05-04 | Information Disclosure | EventBus subscriber exception leaking handler internals | accept | _safe_call prints exception text to server logs only (not returned to any client); single-user/household self-hosted threat model, no remote log access surface introduced this phase |
</threat_model>
