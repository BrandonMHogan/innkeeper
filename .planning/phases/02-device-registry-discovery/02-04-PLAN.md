<objective>
Close the two unresolved gaps from 02-VERIFICATION.md (CR-01 mDNS placeholder-MAC over-fusion, CR-02 frontend/backend path mismatch causing 307 redirects). Both gaps were independently identified in 02-REVIEW.md and reproduced live during phase verification.

Purpose: Phase 2's goal promises "fused multi-source identity" (not over-fused) and a working register/list flow from the real frontend. Both gaps directly undermine those promises (DISC-01 fusion correctness, DISC-02/DISC-04 register/list reachability).
Output: A guard clause in `ingest_mdns` that skips identity resolution when there is no usable identity signal (replacing the unconditional placeholder-MAC call), a named constant replacing the magic placeholder-MAC string, a corrected frontend API client path matching the backend's canonical mount point, and one regression test per gap.
</objective>

## Artifacts this phase produces

- **`backend/src/routes/capture.py`** — new module-level named constant `_MDNS_PLACEHOLDER_MAC = "00:00:00:00:00:00"` (replaces the inline magic string, per IN-02); new guard clause in `ingest_mdns` that skips `record_observation` and returns `{"ok": True, "skipped": "no identity signal"}` when `payload.hostname` is falsy.
- **`backend/tests/test_capture.py`** — two new regression tests: `test_mdns_ingest_without_hostname_does_not_collide` (proves two distinct hostname-less mDNS observations do not collapse into one `DiscoveredIdentity` row) and `test_mdns_ingest_with_hostname_still_resolves_identity` (proves the guard does not regress the hostname-present fusion path).
- **`frontend/src/lib/api.ts`** — `listDevices()` and `registerDevice()` call sites updated to target the canonical `/api/devices/` (trailing slash) backend mount point instead of the non-canonical `/api/devices`.
- **`backend/tests/test_devices.py`** — new regression test `test_list_devices_canonical_path_no_redirect`, which asserts `GET /api/devices/` returns 200 (no redirect) and the control case `GET /api/devices` still returns 307 with `Location` exactly `http://test/api/devices/`.
