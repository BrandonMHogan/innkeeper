## Decisions Made
- Confirmed via direct PyPI/source inspection that `mac-vendor-lookup`'s `AsyncMacLookup` resolves its OUI snapshot from a build-time-populated cache path (`sys.prefix/cache/mac-vendors.txt`, populated during `pip install`), not a runtime network call — satisfies CLAUDE.md's no-telemetry constraint without needing extra guarding code in `infer()`
- Upsert semantics for the two new signal columns are full-overwrite per observation (matching existing `mac`/`hostname` behavior), not a field-level merge — verified via direct SQL inspection that this is the correct, intended behavior per the plan's literal `set_={...}` spec
- Test isolation note: `test_upsert_persists_mdns_dhcp_signals` uses a fresh session per phase rather than reusing one session across multiple `record_observation` + `select` calls, to avoid a pre-existing SQLAlchemy identity-map staleness artifact (Core `on_conflict_do_update` statements don't refresh already-loaded ORM instances within the same session) — this is a test-construction detail, not a production code change
