## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-------------------|
| T-02.1-05 | Information Disclosure | Raw-signal popover content rendered in DeviceCard.svelte | accept | Same disposition as T-02.1-01 (Plan 01) — the frontend only renders fields the backend has already decided are safe to expose to the authenticated dashboard user; no additional client-side data collection or storage occurs |
| T-02.1-06 | Tampering (XSS via rendered strings) | Raw OUI vendor string / mDNS service type / DHCP vendor class values rendered as popover text | accept | Svelte's default text interpolation (`{value}`) HTML-escapes all rendered values — no `{@html}` is used anywhere in this plan's markup, so a malicious raw string (e.g. a crafted DHCP vendor-class string containing `<script>`) cannot execute; this is Svelte's default behavior, not a control this plan needs to add |
